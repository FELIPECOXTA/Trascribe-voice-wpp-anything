# Referência visual do Google Stitch

A proposta de interface mobile foi enviada no arquivo `stitch_audio_transcriber_studio.zip` e em capturas do Google Stitch.

Este PR incorpora as cores, superfícies, foco, responsividade e botões de ação em `apps/web/src/stitch.css`. O HTML do Stitch é um mockup visual e **não** deve substituir componentes React nem a lógica da API.

Próximas etapas: revisar fidelidade visual em navegador, validar layout desktop/mobile e anexar os screenshots originais ao projeto quando necessário.
